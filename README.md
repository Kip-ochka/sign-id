# SIGNING

Веб-приложение для подписания документов по ссылке из SMS. Стек проекта — React 17, TypeScript и Vite. Требования, API и статус приёмки описаны в [документации SIGNING](docs/signing/README.md).

Требуется Node.js 20.19+ в ветке 20, 22.13+ в ветке 22 или 24 и выше.

## Разработка

```sh
npm ci
npm run dev
```

Vite запускает фронтенд. Приложение считывает `id` из SMS-ссылки и обращается к штатному API по относительным путям `/proxy/services/…`. Для сквозного запуска эти пути должны вести на бэкенд через тот же origin, а на рабочем месте должны быть установлены Browser Plug-in и КриптоПро CSP и доступен действующий сертификат.

## Границы MVP

CHECK подписывает один тестовый документ. SIGNING последовательно подписывает документы группы одним сертификатом в режиме `single/other/detached` с профилем PKCS#7 и отправляет полный комплект. Для остальных режимов приложение показывает локальный STATUS. Требования к CryptoPro и условия внешней приёмки описаны в [криптографическом контракте](docs/signing/CRYPTO_CONTRACT.md).

## Проверки и форматирование

| Команда                | Назначение               |
| ---------------------- | ------------------------ |
| `npm test`             | Запустить тесты Jest     |
| `npm run typecheck`    | Проверить типы           |
| `npm run lint`         | Запустить ESLint         |
| `npm run format:check` | Проверить форматирование |
| `npm run format`       | Отформатировать файлы    |

Для отдельной автоматической проверки обработки HTTP 303 нужен Chromium. Скрипт сам поднимает временный HTTP-сервер на loopback. Команда и протокол приведены в [контракте API](docs/signing/API_CONTRACT.md#проверка-ac-22).

## Сборка

```sh
npm run build
npm run preview
```

Команда `build` проверяет типы перед сборкой. Готовая сборка находится в `dist/`. Команда `preview` запускает её локальный предпросмотр.

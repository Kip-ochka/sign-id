# React 17 + Vite

Постановка нового процесса подписания: [документы и последовательные задачи](docs/signing/README.md). Для будущих агентов: [AGENTS.md](AGENTS.md). Этот пакет описывает будущую реализацию; текущий интерфейс пока остаётся стартовым.

Стартовый проект на TypeScript с React и React DOM версии 17.0.2.

Требуется Node.js 20.19+ в ветке 20, 22.13+ в ветке 22 или 24 и выше.

## Разработка

```sh
npm install
npm run dev
```

Откройте адрес, который Vite выведет в терминале. Компонент со счётчиком находится в `src/App.tsx`, а точка входа с `ReactDOM.render` — в `src/main.tsx`.

## Проверки и форматирование

| Команда                | Назначение               |
| ---------------------- | ------------------------ |
| `npm run typecheck`    | Проверить типы           |
| `npm run lint`         | Запустить ESLint         |
| `npm run format:check` | Проверить форматирование |
| `npm run format`       | Отформатировать файлы    |

## Сборка

```sh
npm run build
npm run preview
```

Команда `build` проверяет типы перед сборкой. Готовая сборка находится в `dist/`. Команда `preview` запускает её локальный предпросмотр.

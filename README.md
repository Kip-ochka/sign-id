# SIGNING

Клиент подписания документов: React 17, TypeScript, Vite.

Требуется Node.js 20.19+ (ветка 20), 22.13+ (ветка 22) или 24+.

## Запуск и сборка

Для локальной разработки клиент использует UI-компоненты из `local-ui/`.

1. В корне репозитория выполните `npm ci` для клиента и
   `npm ci --prefix backend/mock-api` для мок-сервера.
2. Запустите `npm run mock` и `npm run dev` в отдельных терминалах.
3. Откройте [локальный клиент с тестовым id](http://localhost:5173/?id=mock-inquiry)
   в браузере с расширением КриптоПро. Если откроется экран настройки рабочего
   места, нажмите «Запустить проверку».

`npm run typecheck`, `npm run lint`, `npm run build` — проверки и сборка.
Результат сборки — `dist/`; предпросмотр — `npm run preview`.

Приложение читает `id` из URL и обращается к API по относительным путям
`/proxy/services/…`. Dev-прокси направляет запросы на `127.0.0.1:3001`;
порт задаётся через `MOCK_PORT`. В production API доступен на origin клиента.
Для подписания нужны Browser Plug-in, КриптоПро CSP и действующий сертификат.

Тесты, тестовые UI-моки, фикстуры, галерея и рабочая документация
исключены из Git. Команда `npm test` использует эти локальные файлы.

Самостоятельное серверное приложение: [backend/mock-api](backend/mock-api/README.md).

# SIGNING

Веб-приложение для подписания документов по ссылке из SMS. Стек проекта — React 17, TypeScript и Vite. Требования, API и статус приёмки описаны в [документации SIGNING](docs/signing/README.md).

Требуется Node.js 20.19+ в ветке 20, 22.13+ в ветке 22 или 24 и выше.

## Разработка

```sh
npm install
npm run dev
```

Приложение считывает `id` из ссылки при загрузке. Для сквозного запуска с сервером нужны действительная тестовая заявка и доступные по тому же адресу маршруты `/proxy/services/...`. Для локальной проверки с синтетическими ответами используйте браузерный сценарий ниже.

Для просмотра экранов на фикстурах откройте `/docs/signing/ui-preview.html?case=signing` на адресе Vite.

## Границы MVP

CHECK подписывает один тестовый документ. SIGNING последовательно подписывает документы группы одним сертификатом в режиме `single/other/detached` с профилем PKCS#7 и отправляет полный комплект. Для остальных режимов приложение показывает локальный STATUS. Требования к CryptoPro и условия внешней приёмки описаны в [криптографическом контракте](docs/signing/CRYPTO_CONTRACT.md).

## Проверки и форматирование

| Команда                | Назначение               |
| ---------------------- | ------------------------ |
| `npm test`             | Запустить тесты Jest     |
| `npm run typecheck`    | Проверить типы           |
| `npm run lint`         | Запустить ESLint         |
| `npm run format:check` | Проверить форматирование |
| `npm run format`       | Отформатировать файлы    |

Команды ниже запускают Chrome и синтетический HTTP-сервер на loopback. Второй аргумент UI-сценария задаёт каталог скриншотов.

```powershell
node docs/signing/check-browser-303.mjs 'C:/Program Files/Google/Chrome/Application/chrome.exe'
node docs/signing/check-browser-ui.mjs 'C:/Program Files/Google/Chrome/Application/chrome.exe' (Join-Path $env:TEMP 'signing-ui')
```

Доступа к интеграционному стенду в рамках проекта не будет. Клиент реализован по требованиям, HTTP-сценарии проверяются в браузере с локальным синтетическим бэкендом. [Протокол проверки](docs/signing/API_CONTRACT.md#проверка-ac-22).

## Сборка

```sh
npm run build
npm run preview
```

Команда `build` проверяет типы перед сборкой. Готовая сборка находится в `dist/`. Команда `preview` запускает её локальный предпросмотр.
